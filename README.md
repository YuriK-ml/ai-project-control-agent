# AI Project Control Agent

Проект предназначен для анализа данных проектного графика. Адаптер преобразует WBS из сохранённых ответов PLAN-R Public API в Canonical Project Model. Процедура контроля проверяет сроки и согласованность статуса с прогрессом.

Текущий MVP: локальные PLAN-R fixtures → адаптер → Canonical Project Model → контрольные проверки → AI-анализ → CLI или Streamlit.

PMIS/PLAN-R остаётся system of record. Canonical Project Model служит временным внутренним представлением для анализа и существует в памяти на время запуска.

## Структура

| Путь | Назначение |
| --- | --- |
| `app.py` | Запуск ручной проверки |
| `streamlit_app.py` | Локальный интерфейс выбора проекта и запуска контроля |
| `src/adapters/planr/adapter.py` | Чтение атрибутов и преобразование WBS |
| `src/canonical/model.py` | Модель элемента графика |
| `src/workflows/` | Модель результата и проверка актуальности графика |
| `src/agent/` | Подготовка контекста и один вызов OpenAI для анализа графика |
| `tests/` | Unit-тесты правил контроля и контекста |
| `src/ui/` | Пустой каталог |
| `data/fixtures/planr/project_01/` | Исходные `eps.json`, `wbs-attributes.json` и `wbs.json` |
| `requirements.txt` | Официальный Python SDK OpenAI, python-dotenv и Streamlit |

Реальные PLAN-R fixtures хранятся локально и исключены из Git. Перед запуском поместите `eps.json`, `wbs-attributes.json` и `wbs.json` в `data/fixtures/planr/project_01/`. Streamlit также обнаруживает другие директории проектов в `data/fixtures/planr/`.

## Интерфейс в браузере

После установки зависимостей и настройки корневого `.env` запустите из корня проекта

```sh
streamlit run streamlit_app.py
```

Выберите проект и дату анализа, затем нажмите «Запустить контроль проекта».

## Ручная проверка

Установите зависимости на Python 3.9 или новее:

```sh
python -m pip install -r requirements.txt
```

В корне проекта скопируйте `.env.example` в `.env` и заполните `OPENAI_API_KEY`. Если переменная уже задана в окружении, приложение использует её значение. Локальный `.env` исключён из Git.

```sh
python app.py
```

Скрипт читает три файла, выводит нарушения на 14 ноября 2026 года и передаёт весь график и результаты контроля в OpenAI для анализа. Контроль принимает `date` и сравнивает её с календарной датой окончания в UTC.

Просмотр точного JSON-входа для модели работает без вызова API

```sh
python app.py --show-context
```

Запуск unit-тестов

```sh
python -m unittest discover -s tests -v
```

Даты представлены как `datetime` в UTC, а JSON `null` сохраняется как `None`. Поля `predecessors` и `successors` содержат исходную строку связи или `None`. В сохранённых данных заполненные строки содержат по одному коду. Формат нескольких связей пока неизвестен, поэтому строки сохраняются целиком.
