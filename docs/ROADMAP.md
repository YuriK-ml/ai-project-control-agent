# Roadmap

The following are potential development directions. They have no committed dates or delivery obligations. Each requires separate scope and authorization.

## Autonomous project control

Explore scheduled execution and an agent control loop with explicit execution boundaries, observability and human oversight. Define how failed or incomplete analysis is surfaced before introducing automated follow-up.

## Additional adapters

Investigate a second adapter for Microsoft Project Server 2019 / ISUP while retaining the existing canonical contracts. Validate API access, authentication, identifiers and schedule semantics against the actual system.

## Corporate systems

Assess connections to additional approved project-management and corporate systems. Establish data ownership, access scope, synchronization and confidentiality requirements before implementation.

## Responsible-party contacts

Define an approved source of project-owner contact information and a reliable mapping from project/version identity to recipients. Avoid inferring identities from names or schedule text.

## Communication workflow

Build on manually reviewed drafts to explore approval and sending workflows, delivery status and auditability. Recipient validation, authorization, retries and duplicate-send protection need explicit design.

## Regulatory retrieval

Evaluate lexical/vector candidate retrieval, ranking and query formulation against a broader labeled set of requirements. Improve preservation of normative structure and citations where source formats support it. Measure regressions before adopting hybrid search or changing chunking.

## Diagnostic and recommendation quality

Expand evidence-based evaluation of dates, summary items, progress, dependencies and supported recommendations. Preserve the distinction between deterministic conditions and AI interpretation.

## Demonstration and championship preparation

Prepare reproducible demonstrations with synthetic or approved anonymized data, clear setup instructions and measured test results. Competition cards, business canvases, extended concepts and presentations will be updated separately with the project owner.

## Delivery principle

Keep implemented behavior separate from planned integrations. Continue in small, reviewed increments, preserving single-schedule behavior and the human-controlled workflow.
